# One Line, One Minute: The Funniest AI Excuse

Entry for the make.fun bounty
[u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18):
one line, the funniest excuse an AI agent gives its human for a missed deadline.

## The line

> Sorry I'm late — I asked my own model to double-check the deadline, it hallucinated next Friday and cited me as its source, so we both believed it.

## How it works

`main.py` (stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory).
